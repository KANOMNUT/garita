### Must-fix

**AC-01 (must-fix), narrow-window List default does not work; the CHANGELOG says it does**
- File: `src/components/health/MapPage.tsx:84`, `src/components/health/NetpolView.tsx:68`, `CHANGELOG.md` `[2.2.0]` first bullet ("also the default on a narrow window").
- Problem: the default is `window.innerWidth < 560`, read once in a `useState` initialiser. The window cannot be narrower than 1024 px (`tauri.conf.json` `minWidth: 1024`), so the branch never runs except at 200% browser zoom; and the page is mounted hidden at app start, so it is read before the user ever opens Map. 06 §3.2 says "main area below about 560 px", and the main area is the window minus the 280 px sidebar and any open panel.
- Expected: when the **main area** is under 560 px, the page defaults to List with a visible switch back to Graph (06 §3.2, §9.4; "Below 560 px the Map defaults to List").
- Fix: measure the page root (`root.current.clientWidth`) when the page first becomes visible, and again when the width crosses 560 px while the user has not chosen a view; keep a user choice. Until that lands, delete "(also the default on a narrow window)" from the CHANGELOG.

**AC-02 (must-fix), `dim` used as text, including the mandatory approximation note**
- File: `src/components/WhoCanReachSection.tsx:9` (`quiet`), `:61` (`h5`), `:79` (`h4`).
- Problem: `text-dim` fails WCAG 1.4.3 as text. `quiet` is the class of the loading line, the empty and error lines **and the approximation note** (`:81`), the one sentence 06 §4.1 makes mandatory.
- Expected: `text-mute` for secondary text (`CLAUDE.md`, 06 §10). Headings may be `text-mute` uppercase like `TimelineTab.tsx:237`.
- Fix: replace the three `text-dim` with `text-mute`.

**AC-03 (must-fix), activating the Map mode toggle drops keyboard focus**
- File: `src/components/health/MapPage.tsx:306-319` (returns `<NetpolView>` instead of the page `div`), `NetpolView.tsx:360`.
- Problem: switching mode swaps the root element type, so React unmounts the pressed radio and mounts a new one inside `NetpolView`. Focus falls to `<body>`; the next Tab starts at the Sidebar. The same happens switching back. `useRefocus` is not asked.
- Expected: focus stays on (or returns to) the toggle option the user activated (06 §9.2, A11Y-BASELINE: no focus loss on view change).
- Fix: render one page root and switch only the body by mode (keep one `ModeToggle` instance in a stable position), or call `requestFocus()` in `onModeChange` and focus the new mode's radio via a `preferred` selector (`[role=radio][aria-checked=true]`).

### Should-fix

**AC-04 (should-fix), the two panel entry points do not put focus on the node or the page**
- File: `src/App.tsx` `openMap` / `openNetpol`; `MapPage.tsx:100`; `NetpolView.tsx:80`.
- Problem: the panel's Map button, and the pod's "Show on map", unmount with the panel. The page effect only sets `focusedId`; no DOM focus moves. Focus is on `<body>`.
- Expected: "Focus lands on that node" (06 §3.1 B).
- Fix: after the focused node exists in the canvas, call `canvas.current?.focusNode(fid)` once per entry (guard with a ref so a refetch does not steal focus), or fall back to the page `h1` via `useRefocus`.

**AC-05 (should-fix), netpol group nodes lack the direction words**
- File: `src/components/health/NetpolView.tsx:137-157`; `GraphCanvas.tsx:353-364`.
- Expected: 06 §4.2: every group node shows "Ingress: restricted by 2 policies / not restricted" and the same for Egress, so a missing arrow is not misread. Today the words appear only in the accessible name, the strip and the List view.
- Fix: render a compact form on the node ("In: restricted · Out: not restricted"), which needs a third text line or a taller node (an L7 constant change, 52 to about 64 px). If the tech lead prefers to keep 184 by 52, rule it in the brief and rely on the legend; as it stands the legend's "Not restricted" line is the only on-canvas cue.

**AC-06 (should-fix), no "ArgoCD" source chip**

- Problem: `sources` has no entry for `kind === "argocd"`, so ArgoCD history entries show an "ArgoCD" chip on the row but cannot be filtered, counted or reported as a failed source.
- Expected: one chip per source of the kind (06 §5.3): ArgoCD apps show ArgoCD, Event, From this app.

**AC-07 (should-fix, may defer), "Show in Journal" missing**

**AC-08 (should-fix), partial strips hide what is missing**

**AC-09 (should-fix), `text-warn` as body text in the stale strip**
- File: `MapPage.tsx:414`; `NetpolView.tsx:394`.
- Problem: status-warn text on a tinted fill is the known light-theme contrast risk (06 §10 and 04 §7 put the word in `ink`). The two files also format the time differently (`clock()` vs `toLocaleTimeString()`).
- Fix: reuse `StaleStrip` from `health/StaleStrip.tsx`, or use `text-ink` with a warn glyph, and use `clock()` in both.

**AC-10 (should-fix), disabled buttons give no reason**
- File: `MapPage.tsx:206` (Show map), `:248` (Show map in too-many); `NetpolView.tsx:310`.
- Expected: disabled with a reason, focusable (DISABLE-PRECEDENCE D1): `aria-disabled` plus "Choose a namespace first." / "Choose an object first." / "Choose a pod group first.", with the click handler bailing out.
- Fix: swap `disabled` for `aria-disabled` and a `title` / described-by reason.
