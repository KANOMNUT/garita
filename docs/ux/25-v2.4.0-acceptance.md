## 0. What this document is based on, and what it is not

**Evidence.** Task V1 drove the app in Chromium (Playwright) against Vite with a mocked `window.__TAURI_INTERNALS__` and sample data, and saved 284 PNG files in both themes plus 6 marketing shots. The index is `visual/index.md` in the V1 scratchpad (`/tmp/claude-0/-home-user-garita/f4fdec7d-6df0-5838-af75-f4d6d23d0b64/scratchpad/visual/`). I opened the shots named in the Evidence column below myself (about 80 of the 284, light and dark, and all 6 marketing shots) and read the code behind each defect that goes into FX5, and behind D4, D5, D6, D7 and D9. Items 3, 9, 13, 20 and 21 also rest on V1's DOM notes (`logs/*.json`), because a PNG cannot show a `title`, an `aria-*` value, a computed animation or `document.activeElement`.

**Limits, stated once.**

- This is Chromium on Linux with a mocked backend. It is not WebKit (macOS), not WebView2 (Windows), not WebKitGTK, and not a real cluster. Every cluster answer (Terminating timing, the 403 text, `SelfSubjectAccessReview`, the ArgoCD shape, metrics samples) was invented by `mock.js`. A pass here means "the UI draws and behaves as specified on this data", not "works against a cluster".
- There is no Tauri window chrome: no OS title bar, no drag region, no native file dialog.
- The monospace face may differ from the shipped one (`index.md` says the capture fell back to DejaVu Sans Mono; `fc-match "JetBrains Mono"` now resolves, so the next capture should be checked with `document.fonts.check('12px "JetBrains Mono"')`).
- The app's minimum window is 1024 x 640 (`src-tauri/tauri.conf.json` `minWidth`/`minHeight`). The shots at 1024x600 (`01f`), 1024x480 (`01g`) and 1280x400 and 1280x480 (`06c`) are below the minimum height. They are stress tests, not supported sizes, and no finding below depends on them alone.
- Native tooltips (`title`) cannot be seen in a screenshot. Everything that depends on one is "owed on a real build".

**Result words.** *pass*: the shots show what the spec says. *partial*: part passes, part is not visible here or has a finding. *fail*: the shots show the spec broken. *not checkable here*: a still image or this environment cannot show it.

## 3. Defects

Severity follows the agent rules: **Critical** blocks the task or fails WCAG 2.1 AA with no cheap workaround; **Significant** is friction or an inconsistency; **Polish** is minor. "Introduced" means a commit in `git log 4e11176..HEAD` created the behaviour (checked with `git blame` or `git log -S`); "older" means it is in the base or the root commit `b0fc013`.
