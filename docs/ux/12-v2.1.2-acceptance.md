## 2. Fix list for frontend-engineer

**MUST**

- **M1. Gap between host and port.** In the CtxRow proxy line, host and `:port` are sibling flex children under `gap-1`, so the row reads `proxy.corp :3128` and `[::1] :3128`. Heuristic: consistency with the spec (`host:port`), and copy/paste. Fix: wrap them in one `<span className="mono flex min-w-0"><span className="truncate min-w-0">{host}</span>{port && <span className="shrink-0">:{port}</span>}</span>`. Truncation behaviour stays as specified.

**SHOULD**

- **S1. Dismiss button has no accessible name.** `ClusterAccessBanner`'s `✕` button reads as a bare glyph, and with `role="alert"` it is now announced as part of the alert. Add `aria-label="Dismiss"` (WCAG 4.1.2). Pre-existing, but this commit made it more visible.
- **S2. Query-error banner is not an alert.** When `access` is undefined and `queryError` is set, `alert` is false, so a failed check is silent to screen readers. Add that case to `alert` (`|| (!access && queryError)`), or accept it and note the decision.
- **S3. Proxy config errors arrive as state `auth`.** `client_for_context` fails on `effective_proxy`, and `check_cluster_access` maps that failure to `state: "auth"`, so "This proxy type isn't supported: https..." shows in the amber (`warn`) strip, with no `role="alert"`, and without the proxy lead-in. The copy is still readable, so this is not a blocker. It is a product and scope decision for tech-lead: either give config errors their own state or class, or accept `auth`. No frontend change until that is decided.

**NIT**

- **N1. Long unbroken text in the banner.** `whitespace-pre-wrap` does not break long words, so a long ctx name in line 1 or a long URL in line 3 can overflow. Add `break-words` on the `<p>` elements, or `break-all` on line 3.
- **N2. "aren't supported yet"** in the SOCKS5 credentials string promises a future feature. Consider dropping "yet" (backend, rust-engineer).
- **N3. Existing `text-dim` lines** (`cluster`, `context defined in`) still fail 1.4.3. Out of scope for this release, as agreed in brief §0.4; keep it on the Polish list.
