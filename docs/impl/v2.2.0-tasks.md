### FZ3. F1 layout and renderer spec (own layered layout)

`src/utils/graphLayout.ts` is pure, has no React and no `Date`/`Math.random`, and runs synchronously.

**Input:**
- `LayoutNode { id: string; column: number }`;
- `LayoutEdge { from: string; to: string }`.

The page passes only drawable nodes: already hidden and grouped, with at most 400 of them. **The draw cap is the page's job.** Above 400 the page renders the too-many state and never calls `layout`.

**Constants** (CSS px at 100%):
- node 184 × 52 (UX L7);
- column pitch 256 (gap 72);
- row pitch 68 (gap 16);
- dummy slot pitch 16;
- island gap 40;
- padding 24.

**Map columns** (`MAP_COLUMN` in `resourceMap.ts`, UX L1):

| Column | Kinds |
|---|---|
| 0 | `ing`, `gw` |
| 1 | `httproute` |
| 2 | `svc`, `hpa` |
| 3 | `deploy`, `sts`, `ds`, `cron` |
| 4 | `rs`, `jobs`, `pdb` |
| 5 | `pods` and pod groups |
| 6 | `pvc`, `cm`, `sec` |
| 7 | `pv` |

With these columns no map relation joins two nodes of the same column. `attaches-to` (column 1 → 0) is the one edge that points left.

**Algorithm:**

1. **Normalise.**
   - Sort nodes by `id`.
   - Drop edges with an unknown endpoint, and self-edges (the details strip states self-reachability in netpol).
   - Dedupe edges by `from|to`.
2. **Columns.**
   - **Map:** `MAP_COLUMN[kind]`.
   - **Netpol:** `rankColumns(groupIds, edges, pseudoSrc, pseudoDst)`:
     1. DFS from each node in id order, visiting neighbours in id order. An edge to a node on the DFS stack is a back edge and is reversed **for ranking only**.
     2. Rank by longest path in the resulting DAG (rank 0 = no incoming edge).
     3. Shift groups to columns 1..k. Source-side pseudo-nodes go to column 0 and destination-side pseudo-nodes to column k+1.
     4. A pseudo-node used on both sides becomes two layout nodes, `src:<id>` and `dst:<id>`, with the same label.
3. **Islands.**
   - Islands are the connected components over undirected layout edges, ordered by smallest node id (L2).
   - One-node islands form the final **"Not connected"** band. It is a wrapping grid sorted by `(column, id)`, as wide as the widest island and at least 4 slots.
4. **Long edges.**
   - An edge between columns `a` and `b` with `|a − b| > 1` gets one dummy per intermediate column, id `~<from>|<to>|<column>`.
   - A same-column edge gets no dummies and is drawn straight. None exist in map mode.
5. **Order within each column, per island.**
   1. Initial order: real nodes by id. Each dummy goes beside the position of its edge's source.
   2. **4 barycenter sweeps**, alternating down (columns 1..max, key = mean index of neighbours in the previous column) and up (columns max−1..0, key = mean index of neighbours in the next column).
   3. A node with no neighbour on the swept side keeps its current index as key.
   4. Each sweep is a stable sort by `(key, current index)`.
   5. No crossing counting, no transposition. This is a deliberate ceiling; mark it `ponytail:`. The upgrade path is a transposition pass, then `@dagrejs/dagre` with user OK.
6. **Coordinates.**
   - `x = 24 + column × 256`.
   - Within an island, each column stacks its slots (node 68, dummy 16) and is centred vertically in the island band.
   - Bands stack top to bottom with a 40 gap; "Not connected" comes last.
7. **Edges.**
   - Each edge is a polyline. It starts at the source's right-middle (left-middle when it goes left), passes through its dummy centres, and ends at the target's left-middle (right-middle when it goes left).
   - Straight segments, arrowhead at `to` (L9).
8. **Determinism (L3).** Every sort has an id tie-break, so `layout` is a pure function of the sets.
9. **Stability (L4).**
   - `layoutKey` = sorted node ids + sorted `from>to`. It ignores status, detail and labels.
   - `GraphCanvas` memoises the layout on the key.
   - When the key changes: re-layout, keep the zoom, and scroll so the focused node keeps its screen offset. If the focused node is gone, focus the next node in reading order and announce "Removed from the map: …" (UX 9.3).
10. **Reading order** (`readingOrder`): islands in order, columns left to right, slots top to bottom, dummies excluded. It drives roving focus, `aria-posinset`/`aria-setsize` and `Home`/`End`.

**Renderer** (`GraphCanvas.tsx`):
- A scroll container holds a sized inner box, scaled by CSS `transform: scale(z)` with origin `0 0`; zoom ranges 0.5 to 2. One `<svg>` edge layer sits under absolutely positioned **HTML `<button>` nodes**, so focus, accessible names and Tailwind tokens come for free.
- Strokes use `currentColor` with `text-mute`/`text-ink` classes. Line style comes from `strokeDasharray` by family (UX 2.3). There are no colour literals, so G1 passes.
- The canvas is **one tab stop** with roving focus. It implements the keys in UX 2.6, with `+`, `-` and `0` scoped to it (K1), and Esc follows the `ui.md` layering. No animation (L5).
- Props:
  - `nodes`: `{ id, column, kindLabel, name, status?, accessibleName }[]`;
  - `edges`: `{ from, to, family: "solid" | "dashed" | "dotted", label? }[]`;
  - `focusedId`, `onFocus(id)`, `onOpen(id)`, `ariaLabel`.
- The details strip and legend belong to each page.

**`GraphList.tsx`** (D6a): `sections: { heading, count, rows: { id, status?, name, relations: string, onOpen }[] }[]`. It is a plain grouped list with one Open button per row.

**Tests** (`graphLayout.test.ts`):
- shuffled input gives identical output;
- columns are respected;
- islands are ordered and singletons go to the band;
- a 0→3 edge gets 2 dummies;
- a 2×2 crossing fixture comes out uncrossed after the sweeps;
- `rankColumns` on A→B→A ranks both and reverses exactly one edge, and ignores a self-loop;
- pseudo `src:`/`dst:` are pinned to the first and last columns;
- `layoutKey` ignores status;
- `readingOrder` excludes dummies.

### FZ4. F3 evaluator spec (`src/utils/netpolEval.ts`)

Input: `NetpolModel` and the namespace. Output: `{ groups, pseudo, edges, selectsNothing: string[] }`. Shapes per D8.

**Matching and groups:**
- `matchSelector(sel, labels)` follows Kubernetes semantics:
  - every `matchLabels` pair must be present;
  - `In`, `NotIn` (an absent key matches), `Exists`, `DoesNotExist`;
  - an empty selector matches all.
- **Groups.** Pods are keyed by their labels minus the D8 ignore list (each key is ignored unless some selector in the model uses it).
  - A group is named after its owner when every member shares one `controller`. `ReplicaSet/<x>-<hash>` becomes `x` when the pod has `pod-template-hash=<hash>` and the name ends in `-<hash>`.
  - Otherwise the name is the sorted `k=v` list; with no labels it is "(no labels)".
- **Restricted.** A group is restricted for a direction when some policy has that type in `policy_types` and its `pod_selector` matches the group's representative labels.

**Peers** (policy in namespace N):
- `podSelector` only: the matching groups of N.
- `podSelector: {}` alone: the pseudo-node "All pods in namespace {N}" (D8).
- `namespaceSelector` only: the pseudo-node "Namespaces: {sel} ({n} matching)", with "All namespaces" for `{}`. If N itself matches, the edges go to N's groups (UX 4.2). With `namespaces` skipped, O7 applies.
- Both selectors: AND, labelled "Namespaces: … · pods: …".
- `ipBlock`: "External {cidr}", plus "except …" when present.
- An empty peer list: the pseudo-node "Anywhere".
- **Amendment (2026-10-17, review G2 M1 and S9):**
  - **Evaluation.** A peer that covers every group of this namespace is an **all-peer**. That means "Anywhere", `podSelector: {}` alone, and any `namespaceSelector` that matches this namespace with no podSelector or an empty one. An all-peer matches every group in the two-sided check, never none.
  - **Drawing.**
    - An all-peer is drawn as its pseudo-node: "Anywhere", "All pods in namespace {ns}", or for a namespaceSelector that peer's namespaces pseudo-node plus "All pods in namespace {ns}".
    - A group edge A → B is drawn only when the traffic is allowed and at least one restricted side matched it through a specific (non-all) peer. Otherwise the pseudo-node edge already shows it, so the complete-digraph case stays collapsed.
  - **"No allow rule found"** is computed from the evaluation, never from the drawn edges.
  - For a direction that is not restricted, the text is "not restricted (any source)" / "(any destination)", never "no allow rule found".

**Edges and ports:**
- **Edge A → B between groups.** Let E be the egress ports A's policies allow toward B (or "any" if A is not restricted for egress). Let I be the ingress ports B's policies allow from A (or "any" if B is not restricted for ingress).
  - Draw the edge when **at least one side is restricted** and `E ∩ I` is non-empty.
  - **Port intersection:** "any" ∩ X = X; numeric `port..end_port` ranges overlap; a named port is kept against any port and labelled "port {name} (name, not resolved)".
- **Edges with pseudo-nodes** evaluate only the in-namespace side (O6).
- `allowedBy` entries read "policy {name}, {ingress|egress} rule {i+1}".
- A policy that selects no pod goes to `selectsNothing`.

**Tests:**
- default-deny ingress;
- allow-from-same-namespace collapsing to the pseudo-node;
- a namespaceSelector matching N;
- ipBlock with except;
- port intersection with `end_port` and a named port;
- an egress-only policy;
- `policy_types` Egress with an ingress section ignored;
- `selectsNothing`;
- StatefulSet pod-name ignored (one group), and kept when a policy selects on it;
- O7.

## 2. Proposed IPC contract (v2.2.0)

### 2.1 #18: `get_resource_map` (new, `commands/map.rs`)

| | |
|---|---|
| Rust | `pub async fn get_resource_map(context: String, namespace: String, focus: Option<String>) -> Result<ResourceMap, String>` |
| invoke | `invoke<ResourceMap>("get_resource_map", { context, namespace, focus })` |
| `focus` | `"<kind>/<name>"`: return only the connected component containing that object (the panel entry point) |

```rust
#[derive(Serialize, Deserialize, Debug, Clone)]
pub struct MapNode {
    pub id: String,         // "<kind>/<namespace>/<name>"; cluster-scoped PVs use namespace ""
    pub kind: String,       // ResourceType id ("pods", "deploy", ...; MapKind in A3)
    pub namespace: String, pub name: String,
    pub status: String,     // "ok" | "warn" | "bad" | "unknown", from the same rules as the list views
}
#[derive(Serialize, Deserialize, Debug, Clone)]
pub struct MapEdge {
    pub from: String, pub to: String,
    pub relation: String,   // "owns" | "selects" | "routes-to" | "attaches-to" | "mounts" | "binds" | "uses-config" | "uses-secret" | "scales" | "protects"
    pub detail: String,     // e.g. "port 80 → 8080", "path /api"; "" when none
}
#[derive(Serialize, Deserialize, Debug, Clone)]
pub struct ResourceMap { pub nodes: Vec<MapNode>, pub edges: Vec<MapEdge>, pub truncated: bool, pub skipped: Vec<SkippedSource> }
```

- Sources in the namespace: pods, deploy, sts, ds, rs, jobs, cron, svc, EndpointSlices (Service status only; `selects` is a selector match), ing, gw/httproute (404 → none), pvc (+ their PVs), cm and sec via `list_metadata` (**names only, never data or type**; `kube-root-ca.crt`/`openshift-service-ca.crt` dropped, Helm release and token Secrets excluded by field selector: audit A0-1, A0-4), hpa, pdb.
- A forbidden source goes to `skipped`. `Err` only for client construction.
- Pure, tested functions: `owner_edges`, `selector_edges` (Service and PDB → pods), `ingress_edges`, `route_edges`, `volume_edges` (incl. projected sources), `env_edges`, `hpa_edges`, `truncate_component(focus, cap)`.

### 2.2 #24: `get_network_policy_model` (new, `commands/netpol.rs`)

| | |
|---|---|
| Rust | `pub async fn get_network_policy_model(context: String, namespace: String) -> Result<NetpolModel, String>` |
| invoke | `invoke<NetpolModel>("get_network_policy_model", { context, namespace })` |

```rust
pub struct LabelSelectorModel { pub match_labels: BTreeMap<String, String>, pub match_expressions: Vec<SelectorExpr> }
pub struct SelectorExpr { pub key: String, pub operator: String, pub values: Vec<String> }
pub struct PeerModel {
    pub pod_selector: Option<LabelSelectorModel>,
    pub namespace_selector: Option<LabelSelectorModel>,
    pub ip_block: Option<IpBlockModel>,
}
pub struct IpBlockModel { pub cidr: String, pub except: Vec<String> }
pub struct PortModel { pub protocol: String, pub port: Option<String> /* number or name */, pub end_port: Option<i32> }
pub struct RuleModel { pub peers: Vec<PeerModel> /* empty = all */, pub ports: Vec<PortModel> /* empty = all */ }
pub struct PolicyModel {
    pub name: String, pub pod_selector: LabelSelectorModel,
    pub policy_types: Vec<String>, pub ingress: Vec<RuleModel>, pub egress: Vec<RuleModel>,
}
pub struct NetpolModel {
    pub policies: Vec<PolicyModel>,
    pub pods: Vec<PodLabels>,              // name + labels, this namespace
    pub namespaces: Vec<NamespaceLabels>,  // every namespace's name + labels (needed for namespaceSelector)
    pub skipped: Vec<SkippedSource>,
}
```

Frontend pure `src/utils/netpolEval.ts` (tested), Kubernetes semantics:
- a pod not selected by any policy of a given type is unrestricted for that type;
- a selected pod allows only the union of its policies' rules;
- an empty `peers` list = all peers; an empty `ports` list = all ports;
- `podSelector` + `namespaceSelector` in one peer = AND;
- `ipBlock` renders as an "External {cidr}" node;
- named ports are shown by name, unresolved.
Output: an allow-edge list among pods in the namespace plus "other namespaces" and "external" pseudo-nodes. Every surface says **approximation**, and why (CNI-specific policies, named ports, node-local traffic).
