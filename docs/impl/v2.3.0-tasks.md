### A3. Contract (frozen)

**Serialisation:** every struct derives `Serialize, Deserialize, Debug, Clone` with **no `rename_all`**. Struct fields are snake_case on the wire, **including fields nested inside an arg** (`target.path_prefix`, `target.service.namespace`). Tauri camelCases **top-level command arg names only** (`stepSeconds`, `allNamespaces`). An `Option` serialises as `null`.

**Rust (`8e8e136` plus FZ1):**

```rust
// commands/observability.rs
pub struct ServiceTarget {
    pub namespace: String,              // DNS-1123 label (launch::valid_namespace)
    pub service: String,                // DNS-1123 label
    pub port: String,                   // 1..=65535, or an IANA port name (<= 15, [a-z0-9-])
    #[serde(default)] pub scheme: Option<String>,      // None | "" | "http" → http; "https"; else Err
    #[serde(default)] pub path_prefix: Option<String>, // None | ""; else starts "/", no "..", [A-Za-z0-9-._~/], trailing "/" trimmed
    #[serde(default)] pub tenant: Option<String>,      // RA-7: None | "" → no header; else X-Scope-OrgID, [A-Za-z0-9!._*'()-], 1..=150
}

pub struct ObservabilityCandidate { pub kind: String /* "prometheus" | "loki" | "victorialogs" */, pub target: ServiceTarget, pub reason: String }
pub struct ObservabilityDiscovery { pub candidates: Vec<ObservabilityCandidate>, pub skipped: Vec<SkippedSource> } // RA-5; problems::SkippedSource { source, reason }; source = namespace or "*"
// commands/prometheus.rs
pub struct MetricSeries { pub label: String /* container; else the pod or node name */, pub points: Vec<(i64, f64)> /* unix seconds, finite value */ }
```

## 7. Risks

| Risk | Mitigation |
|---|---|
| Label-name differences across Prometheus setups | Pod templates follow cAdvisor conventions. Node templates try node-exporter via `node_uname_info`, then cAdvisor root by `node`, then by `instance` (RA-4). The probe surfaces `wrong-service`. Empty series show "No data for this pod in Prometheus." plus the fallback. |
| PromQL/LogQL injection through names | Values are shape-validated, then escaped; newlines are rejected; label names are validated (A4). |
| Large responses | The body cap is enforced while reading; points by step; 20 series; 5,000 lines (T70-5, RA-1). |
| A backend 403/404 misread as RBAC or a missing service | Origin classification (RA-1b). |
| Multi-tenant Loki rejects reads without an org ID | The tenant field (RA-7, O-19). If the service proxy turns out to drop the header, the §6.2 row shows it, and log history is documented as single-tenant only. |
| A stale chart under a different object | `placeholderData` across a range change only; `isPlaceholderData` is "no p95" (A3, F3). |
