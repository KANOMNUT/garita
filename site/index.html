Browse, debug and change Kubernetes clusters without leaving one window.

Garita is a desktop client that talks to the Kubernetes API directly. No kubectl binary needed, and your kubeconfig is never rewritten.

Garita (gah-REE-tah): the lookout turret on a fortress wall.

Desktop app. Open this page on a computer.

macOS (Apple Silicon), Linux (x86_64) and Windows (x86_64). The Windows installers are unsigned, so SmartScreen will warn. Free and open source under Apache-2.0.

What you can do

43 resource kinds

Workloads, networking, config, RBAC and cluster objects, plus every installed CRD, Helm release, ArgoCD Application and Flux resource.

Pods, logs and shells

Stream and filter logs across pods, open a shell in a container, attach a debug container, and read CPU and memory from metrics-server.

Edit with a preview

Change YAML or Helm values and see a server-side dry run and a diff before anything is written.

Health at a glance

Problems, capacity, deprecated APIs and possibly unused objects, from fixed rules. No scores or grades.

Who can do what

Ask which subjects can do a verb on a resource, and see what a service account's bindings grant.

Journal

A local record of every change the app sent, per cluster. Secret values are never recorded.

Built to avoid surprises

  • Read-only mode per cluster turns off the app's write actions; every write shows a confirmation. It is a guardrail in the app, not a security boundary.
  • A colour and label per cluster, so production looks like production.
  • Secret values stay hidden until you click Reveal, and are never shown in diffs or previews.

What it deliberately does not do

  • No kubectl binary dependency.
  • Never writes to your kubeconfig.
  • No server-side apply; edits are JSON merge patches.
  • No node shell, no privileged pods.
  • No AI, telemetry, analytics or crash upload.

Garita checks GitHub once a day for a new version and never sends cluster data. You can turn the check off in Settings.

Install

macOS (Apple Silicon)

Download Garita-macOS-arm64.dmg and drag it to Applications. The app is ad-hoc signed, not notarized, so macOS blocks the first launch. Run once:

xattr -rd com.apple.quarantine /Applications/Garita.app

Or with Homebrew (the cask does this for you):

brew tap KANOMNUT/garita https://github.com/KANOMNUT/garita
brew install --cask kanomnut/garita/garita
Linux (x86_64)
  • Debian/Ubuntu: Garita-linux-amd64.deb
  • Fedora/RHEL: Garita-linux-amd64.rpm
Windows

Windows (x86_64): download Garita-windows-amd64-setup.exe or Garita-windows-amd64.msi.

Unsigned: Windows SmartScreen will warn. Choose "More info", then "Run anyway".

After installing, open a new terminal window to use the garita command.

Or with Scoop:

scoop install https://kanomnut.github.io/garita/scoop/garita.json

Verify downloads: see SECURITY.md.
